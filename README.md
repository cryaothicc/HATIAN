# Hatian

A live, backend-free bill splitting calculator. All state lives in the URL and `localStorage` — no database, no login required. Split bills with your *tropa* in seconds.

**Live:** https://hatian-eta.vercel.app/

## Stack

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS + shadcn/ui
- Motion
- Sonner
- Jest
